## 2. 화면별 기능

### 2.1 메뉴

- 공간 전환(라디오): 내 공간 / DOI 팀. 공간마다 지식·후보·대화·수집이 따로 쌓인다.
- [새 지식]: 초안을 만들고 바로 편집 모드로 연다. [자료 추가]: 자료 추가 모달.
- 홈, 검토 대기(대기 수 배지).
- 지식 검색(AI와 같은 검색 규칙 + 제목·태그 포함 검색), 유형 필터, 지식 목록(유형 아이콘·제목·초안/검토 필요 점·시각).

### 2.2 홈

- 흐름 4칸: 대화·자료 → 지식 후보(대기) → 사람이 확인(확인됨) → 답변 근거로 사용(인용 수). 후보 칸을 누르면 검토 대기로.
- 숫자: 전체 지식(이번 주 추가), 검토 대기 후보, 검토 필요(검토일 지남), AI 인용 수.
- 목록: 최근 바뀐 지식, AI가 자주 쓴 지식, 다시 확인할 지식(검토 필요·오래된 초안), 자료 수집(단계 진행 막대, 결과 조각·후보 수).

### 2.3 검토 대기

- 후보 카드: 유형, 제목, 나온 곳(대화 — 누르면 채팅에서 그 대화를 연다 / 자료), 태그, 요약, 내용 접기.
- 비슷한 지식: 겹침 점수 표시. 45% 이상이면 [기존 지식에 합치기]를 권하고, 60% 이상이면 경고색으로 "같은 내용이면 합치세요".
- 동작: 저장(확인됨으로) · 기존 지식에 합치기(새 버전, 초안으로 되돌려 다시 확인) · 고쳐서 저장(모달) · 버리기.
- 대기 / 처리함 전환.

### 2.4 지식

- 헤더 배지: 유형, 상태(초안·확인됨·검토 필요), AI 작성, 검색 제외.
- 탭: **문서**(요약 강조 + 마크다운 본문 + 마지막 버전 정보) · **출처**(웹·파일·대화·직접 입력, 추가·빼기, 대화 출처는 채팅에서 열기) · **기록**(버전 표, 보기 모달, 되돌리기 — 되돌리기도 새 버전).
- 편집: 제목·요약·본문(미리보기)·변경 메모, Ctrl+S 저장. 내용이 바뀔 때만 버전이 생긴다.
- 삭제: 확인 모달.

### 2.5 채팅

- 헤더: 대화 목록(채팅 창 안에서 목록 보기·새 대화·지우기), 새 대화, 도킹 전환, 접기, 닫기.
- 응답 블록: 생각 과정(접힘) · 지식 검색 카드(찾은 지식과 점수, 눌러서 열기) · 웹 검색 카드 · 답변(마크다운) · **근거 지식**(번호 = 본문 [1]) · **지식 후보 카드**(저장 · 검토함에서 보기 · 버리기, 처리 후 상태 표시).
- 입력: 지식을 연 상태면 "함께 보내기" 제안 칩 → 누르면 첨부 칩. 도구: 지식베이스 검색 켜기/끄기, 웹 검색 켜기/끄기, 모델 선택, 추론 강도. Enter 전송, Shift+Enter 줄바꿈, 응답 중 [■] 중지.
- 대화는 공간마다 쌓이고, 첫 메시지를 보낼 때 대화가 만들어진다.

### 2.6 옵션

- 지식: 분류(유형·상태·다시 확인할 날짜), 태그(추가·빼기), AI 활용(검색 포함 스위치, 인용 수·마지막 인용·처음 만든 곳), 관련 지식, 내보내기(Markdown·요약 복사).
- 홈·검토 대기: AI 지식 검색(방식·찾을 수·후보 자동 제안), 공간 정보, 연결 상태(저장소·AI·임베딩), 예시 데이터로 초기화.

## 3. 상태와 API 계약

- 상태: zustand 하나(`state/workspace.ts`) — 공간, 지식 목록, 후보, 수집 작업, 대화 목록, 지금 화면(`home`·`inbox`·`knowledge`), 열린 지식, 편집 중 id, 설정.
- 화면은 `KnowledgeApi`(`api/client.ts`)만 쓴다. 변경 알림은 `subscribe()`(서버에서는 SSE `/api/events`)로 받아 바뀐 범위만 다시 읽는다 — 다른 창·MCP·자료 수집의 변경도 같은 길로 온다.
- 채팅: `chat(conversationId, request, onEvent, signal)`이 `AgentEvent`를 차례로 준다. 화면과 저장소는 같은 `applyAgentEvent`로 대화 기록을 만든다.
  - 보낸 직후 늦게 도착한 기록 다시 읽기가 새 말풍선을 덮어쓰지 않도록 실행 번호로 막는다(`useAgentSession`).
- 브라우저 저장(localStorage): 공간, 마지막 화면, 공간별 대화, 검색 설정, 테마(`doi-kb-theme`), 채팅 표시 방식(`doi-chat-display-mode`), 모델·추론 강도·검색 토글.

## 4. 데모 모드 (서버 없음)

| 기능 | 데모 동작 | 서버가 붙으면 |
|---|---|---|
| 저장 | localStorage(`doi-kb-demo-v1`), 처음엔 예시 데이터 | PostgreSQL + pgvector(로컬 PGlite) |
| 검색 | 키워드 점수(한국어 두 글자 조각, 검색어 조사 떼기) | 키워드 + 벡터 혼합 |
| AI 응답 | 지식 검색 결과로 만든 예시 답변. "기억해줘"는 후보 생성, 조사 요청은 웹 검색 카드(예시 결과) | Claude 에이전트 루프(도구: knowledge_search·propose 등) |
| 자료 추가 | 텍스트·Markdown은 내용을 읽어 후보, 다른 형식은 자리만 만든다. 단계는 타이머로 진행 | 파일 읽기 → 조각내기 → 임베딩 → 후보 추출 |

## 5. 반응형·테마·접근성

- 셸 기준(레이아웃 CSS): ≥960px 3단, <960px 메뉴+콘텐츠 후 채팅·옵션 아래로, <640px 1단. 960~1099px에서 채팅을 도킹하면 메뉴 180px → 버튼을 한 줄씩 쌓는다.
- 홈·검토 대기는 가운데 칸 너비(`kb-view` 컨테이너)로, 채팅은 채팅 칸 너비(`kb-chat` 컨테이너, ≤300px면 머리 아이콘·추론 강도 숨김)로 바뀐다.
- 테마: `bricks-light` / `bricks-dark`, 첫 페인트 전에 적용.
- 한국어 문구, 아이콘 버튼 aria 레이블, 목록은 `role=list`/`listitem` 안에 버튼, 키보드로 채팅 창 이동·크기 조절(원본 동작).
